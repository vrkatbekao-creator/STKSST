# 選戰騎士團：首都篇

React + PixiJS 雙語本機競選戰棋 **v0.5.0**。台北 12 行政區、共用六角格、藍／橙／白三方、各三人小隊與 28 天日夜競選。

本輪新增三名虛構主將、重裝駐守、遠程範圍宣講、刺客朝向／背襲及六種十月驚奇。新聞棚視覺採藍黃與暖橘，研究證據見 COLOR-RESEARCH-2026-10-31.md；實作差異見 PHASE-3-PUNK.md。

本版先選陣營與主將，再展開三方競選。加入自動存檔、立即存檔及首頁續玩，契約見 PHASE-3-SESSION.md。

## 啟動

Windows 可雙擊 `StartGame.cmd`，開啟終端機顯示的 Local 網址。遊玩時保留該視窗，結束按 Ctrl+C。

```sh
npm ci
npm run dev
```

已安裝套件的工作目錄可直接 `npm run dev`。每次成功行動後自動存檔；重新整理後可在首頁按「繼續競選」。語言偏好會保留。StartGame.cmd 固定使用 http://127.0.0.1:5173，請用同一瀏覽器與網址續玩。

存檔限此瀏覽器的一個進度槽；清除網站資料會移除。開始新局前會確認覆寫；目前沒有檔案匯出、多槽或跨裝置同步。

## 遊玩

1. 全市總覽選行政區，切換街區戰棋。選隊員，再點六角格預覽與確認路線；也可由節點清單選地點並前往。
2. 在節點或可通行相鄰格掃街、拜訪或完成主題活動。同節點一般活動每日兩次，第二次反應減弱。
3. 在場地設立治疏嶼（綠橙色）或恰恰肥皂箱（藍白色），完工後派員，主動舉辦每日場次。
4. 控制並駐守 Wonder，達成地方條件爭取日終加成。可調整優先順序，每隊每日最多結算三個。
5. 第 7／21 天政見發表，第 14／27 天辯論，事前準備預告議題。白天切晚上保留 AP；夜間結束由對手行動並結算。
6. 第 2、4、6、8、10、12、14 天公布前一晚民調；第 15–28 天封關，只提供質性小道消息。第 28 天最後夜間結算後比較全市總支持點，同分平手，並解封實際分數與歷史。

隨時切換繁體中文／English，不影響日期、AP、種子、日誌或局勢。三方與續玩規則見 PHASE-3-SESSION.md，基礎規則見 PHASE-3-SPEC.md，遊戲內亦有競選手冊。

## 地理與範圍

官方行政區輪廓、河道、橋梁及 12 個 Wonder 代表點已接入。共 2,859 個六角格、60 個活動節點；真實圖資與遊戲配置分層，資料來源及授權見 design/assets/SOURCES.md。

街廓圖樣、坡地成本與一般活動點是遊戲設計，尚非逐街道路網或實測高程。支持點、人流皆為合成資料。已有本機存檔，尚無音效、帳號或線上功能；平衡與更細街景仍可持續調整。
