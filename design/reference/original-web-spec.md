# 《選戰騎士團：首都篇》網頁版開發規格書
**專案代號：** Capital Tactics Web
**遊戲類型：** Web-based Tactical RPG (限時生存戰棋)
**核心美學：** 競選總部龐克 (Campaign Punk) - 結合新聞跑馬燈、字卡與微縮都市網格。

## 1. 系統架構與技術棧 (Tech Stack)
為了實現極速開發與跨平台分享，本專案採用「前端 UI 與 遊戲畫布分離」的雙層架構：

*   **底層戰棋畫布 (Game Engine / Canvas)：** `PixiJS` (或 Phaser.js)。專門負責渲染六角形/正方形網格、角色 Sprite (Live2D 或像素圖)、A* 尋路演算法與戰鬥特效。
*   **上層 UI 與系統邏輯 (DOM Layer)：** `React.js` + `Tailwind CSS`。直接覆蓋在 Canvas 上方。用來渲染新聞跑馬燈、民調血條柱狀圖、對話框、技能選單。
*   **狀態管理：** `Zustand` 或 `Redux`。確保 React 的 UI 狀態與 PixiJS 的底層數據完全同步。
*   **部署與後端 (Serverless)：** `Cloudflare Pages` (前端託管) + `Cloudflare Workers` (無伺服器邏輯) + `D1/Supabase` (存儲玩家進度與非同步陣營戰數據)。

## 2. 核心機制 (Core Mechanics)
*   **20 回合制 (20 Days of Siege)：** 遊戲僅有 20 個回合。白天掃街（消耗 AP/加經驗），晚上造勢（消耗 AP/加士氣/降健康度）。
*   **行動點數 (AP)：** UI 呈現為「日曆行程方塊」。耗盡時角色無法行動，頭像切換為疲憊差分圖。
*   **士氣與民調 (HP)：** UI 呈現為「新聞台民調柱狀圖」。
*   **十月驚奇 (Random Events)：** 系統將在特定回合隨機拋出全螢幕 Debuff 或增益事件。

## 3. 兵種相剋設定 (Class Counter Triangle)
底層小兵遵循「剪刀、石頭、布」的相剋迴圈，優勢攻擊傷害 +50%：
*   **重裝 (鐵票樁腳)：** 高防低速。剋制 -> 遠程。
*   **遠程 (鍵盤側翼)：** 高攻低防，大範圍 AoE。剋制 -> 刺客。
*   **刺客 (狂熱小草)：** 高機動，背刺傷害加成。剋制 -> 重裝。

## 4. 主將與陣營設定 (法務安全虛構版)
為避免真實政治爭議，所有角色採用「混合戲仿與奇幻轉譯」：
*   **🔵 藍軍主將【將千秋】：** 職業「重裝領主」。身穿深藍動力裝甲的沒落王族。大絕招【萬安警報】(3 回合絕對防禦，但無法移動)。
*   **🟢 綠軍主將【申博衍】：** 職業「認知作戰法師」。賽博龐克風格，攜帶電子黑熊使魔。大絕招【洋流逆襲】(全圖敵軍混亂 Debuff，召喚不受控側翼擾亂陣型)。
*   **⚪ 白軍主將【黃若水】：** 職業「代理執政官」。白袍法務官。大絕招【關鍵少數】(指定網格 AP 反轉，強制敵軍停止交火並啟動交涉)。

## 5. UI/UX 視覺方針 (給前端 AI 的指示)
*   **絕不使用傳統 RPG 羊皮紙風格。**
*   技能施放時，使用 React 彈出「超粗體紅色快報跑馬燈 (Breaking News)」。
*   受到爆擊時，畫面邊緣閃爍紅光，並蓋上巨大的「【獨家】」印章圖示。
*   戰鬥畫面分割為左右兩半，模仿政論節目的連線視窗。
